# The deck on your phone

The panel you see on the phone or tablet is called the **deck**. It works in any modern browser (Chrome on Android is the most tested).

## The deck menu

There is a small **⋮** button in the top-right corner. It opens the menu:

| Option | What it does |
|---|---|
| **Profiles** | Change the profile this device shows (when there are several). |
| **Home / Back** | Go to the profile's home page or the previous one. |
| **Fullscreen** | Hides the browser bars. It rotates the screen to match your grid (wider than tall → landscape) and **is remembered**: after a reload the deck offers to go back to it. |
| **Screen stays on** | Keeps the phone from dimming or locking while the deck is open. On by default. |
| **Edit** | Edit mode on the phone itself (see below). |
| **Full editor** | Opens the editor on the phone (best on a tablet). |
| **Reload** | Reloads the page. |
| **Unpair** | Forgets this device; you'll have to pair it again. |

## Gestures

Each key can react differently to:

- **Tap**: a normal touch.
- **Long press**: touch and hold (0.5 s by default).
- **Double tap**: two quick taps.
- **On press / On release**: the moment you touch and the moment you lift your finger, with no waiting. Perfect for *push to talk*.
- **Sliders**: drag your finger to change the value (volume, for example).

Long-press and double-tap timings, and vibration on tap, are in *Settings → Deck*.

> When a key has *Long press* or *Double tap* actions, a normal tap waits a moment to tell them apart. Keys with only *Tap* respond immediately.

## Editing from the phone

Menu **⋮ → Edit** turns on edit mode: keys get a dashed border.

- **Tap a key** to change its look, actions or state.
- **Tap an empty cell** to create a new key.
- Press **Done** to save, and **Finish editing** in the menu to use the deck again.

It's the same editor as on the PC, adapted to small screens.

## Like an app

In Chrome, menu **⋮ → Add to Home screen**: you get an icon that opens the deck directly. Combine it with fullscreen and it feels like an app.

## When it disconnects

If the PC turns off, OVSD closes or the WiFi drops, the deck shows "Connecting…" and reconnects by itself as soon as it can. No need to reload.
