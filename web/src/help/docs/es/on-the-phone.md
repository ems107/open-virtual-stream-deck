# El deck en el móvil

El panel que ves en el móvil o la tablet se llama **deck**. Funciona en cualquier navegador moderno (Chrome en Android es el más probado).

## El menú del deck

En la esquina superior derecha hay un pequeño botón **⋮**. Abre el menú:

| Opción | Para qué sirve |
|---|---|
| **Perfiles** | Cambiar el perfil que muestra este dispositivo (si hay varios). |
| **Inicio / Atrás** | Volver a la página de inicio del perfil o a la anterior. |
| **Pantalla completa** | Oculta las barras del navegador. Gira la pantalla según la forma de tu rejilla (más ancha que alta → horizontal) y **se recuerda**: si recargas, el deck te ofrece volver a ella. |
| **Pantalla siempre encendida** | Evita que el móvil se apague o se bloquee mientras el deck está abierto. Activado por defecto. |
| **Editar** | Modo edición en el propio móvil (ver abajo). |
| **Editor completo** | Abre el editor en el móvil (más cómodo en tablet). |
| **Recargar** | Recarga la página. |
| **Desvincular** | Olvida este dispositivo; tendrás que emparejarlo de nuevo. |

## Gestos

Cada tecla puede reaccionar de forma distinta a:

- **Pulsar**: un toque normal.
- **Mantener pulsado**: tocar y esperar (0,5 s por defecto).
- **Doble toque**: dos toques seguidos.
- **Al presionar / Al soltar**: justo al tocar y al levantar el dedo, sin esperas. Ideal para *pulsar para hablar*.
- **Deslizadores**: arrastra el dedo para cambiar el valor (por ejemplo, el volumen).

Los tiempos de pulsación larga y doble toque, y la vibración al pulsar, se ajustan en *Ajustes → Deck*.

> Si una tecla tiene acciones de *Mantener* o *Doble toque*, el toque normal espera un instante para saber cuál de ellos has hecho. Las teclas que solo tienen *Pulsar* responden al momento.

## Editar desde el móvil

Menú **⋮ → Editar** activa el modo edición: las teclas se marcan con un borde discontinuo.

- **Toca una tecla** para cambiar su aspecto, acciones o estado.
- **Toca un hueco** para crear una tecla nueva.
- Pulsa **Hecho** para guardar, y en el menú **Terminar edición** para volver a usar el deck.

Es el mismo editor que en el PC, adaptado a la pantalla pequeña.

## Como una app

En Chrome, menú **⋮ → Añadir a la pantalla de inicio**: tendrás un icono que abre el deck directamente. Combínalo con la pantalla completa para que parezca una app.

## Si se desconecta

Si el PC se apaga, OVSD se cierra o pierdes la WiFi, el deck muestra «Conectando…» y se reconecta solo en cuanto vuelve a estar disponible. No hace falta recargar.
